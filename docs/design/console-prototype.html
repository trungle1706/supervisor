Overview

EN · VIreviewerNA

Supervisor watches the AI agents your bank runs. It records every action, stops the dangerous ones before they execute, and keeps evidence that a regulator can check.

Think of a pit boss on a casino floor. The dealers are your agents. The pit boss never deals, but watches every table, steps in when a hand looks wrong, and the cameras keep the tape.

1

Onboard

Read an agent's code and traces. Write its risk profile, its rules and a pull request. Nothing is merged without a person.

2

Watch

Every tool call passes a gate. Hard rules block or pause in milliseconds. AI judges read the rest and only advise.

3

Prove

Decisions go into a signed hash chain. A case file answers the SBV clock. Anyone can verify the chain offline.

Bring a new or existing agent under supervision in six steps. Supervisor reads the code and traces, proposes rules, and opens a pull request. People approve every step.

Nothing is merged automatically. The onboarding agent itself runs under Watch.

1 DiscoverFind the repo, prompts, tools, tables, traces.
2 UnderstandRisk profile with file:line evidence. Decision 33 class.
3 PlanPick checks from the catalogue. Thresholds. Cost.
4 InstrumentRules YAML, tracing hook, dashboard → pull request.
5 LaunchRed-team pack in sandbox. Baseline. Go / no-go.
6 OperateHand over to Watch.

Read-only access. Secrets are scrubbed before any model reads the code. Expected time: about a minute for a small repo.
